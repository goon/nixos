# How to Use the Nix REPL for Debugging

The REPL (Read-Eval-Print Loop) is a powerful, interactive tool to debug your NixOS configuration, inspect options, and test Nix code. 

With our custom `lib/repl.nix`, the REPL will automatically load your entire flake, the `pkgs` set, the standard library (`lib`), and the specific configuration for the host you are currently running on.

## Getting Started

To drop into the REPL with everything pre-loaded, run:

```bash
nix repl lib/repl.nix
```

*(Note: In the future, we can add a `nyx repl` subcommand to your CLI to make this even faster!)*

## What is Loaded?

When you run that command, the following is injected directly into your global scope:
1. `config` - Your fully evaluated NixOS configuration for the current machine.
2. `options` - The entire schema of available options (useful for checking what options exist).
3. `pkgs` - The `nixpkgs` package set.
4. `lib` - The Nixpkgs standard library AND your custom `extendedLib` functions.
5. `flake` - Your entire flake (`inputs`, `outputs`, etc.).
6. `builtins` - Native Nix built-in functions.

## Examples from Your Repo

Here are some real examples of what you can type into the REPL prompt (`nix-repl>`) right now:

### 1. Check if a Module is Enabled
Wondering if your QML dashboard (Yaks) is enabled on this host?
```nix
nix-repl> config.module.session.yaks.enable
true
```

### 2. Inspect a Global Variable
See what your configured standard monospace font is:
```nix
nix-repl> config.globals.userFonts.monospace
"Kode Mono"
```

### 3. Check an Evaluated Path
Check where your Home Manager state directory is pointing:
```nix
nix-repl> config.home-manager.users.${config.globals.username}.home.homeDirectory
"/home/michael"
```

### 4. Test a Library Function
Want to test one of your custom library functions or a standard `lib` function?
```nix
nix-repl> lib.strings.toUpper "hello"
"HELLO"

nix-repl> lib.attrNames config.module.apps
[ "opencode" "nvf" ... ]
```

### 5. Find a Package Version
Check the exact version of the `hello` package your system would use:
```nix
nix-repl> pkgs.hello.version
"2.12.1"
```

## Quick Tips

*   **Auto-completion:** The REPL supports Tab-completion! If you type `config.mod` and press **Tab**, it will auto-complete to `config.module.`. This makes exploring your options incredibly fast.
*   **Print everything:** Be careful trying to print massive objects (like just typing `config` and hitting enter). Nix will try to evaluate and print the *entire* operating system configuration, which can freeze your terminal. Always drill down to a specific value or use `lib.attrNames` to see the keys of a large set.
*   **Exiting:** Type `:q` or press `Ctrl+D` to exit the REPL.
